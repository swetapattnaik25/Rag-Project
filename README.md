
# RAG Project - Ratha Yatra PDF Question Answering

## Overview
This project uses Retrieval-Augmented Generation (RAG) to answer
questions using information retrieved from a Ratha Yatra PDF.

## Technologies
- Python
- Jupyter Notebook
- PyMuPDF
- Sentence Transformers
- ChromaDB
- Google Gemini API

## Project Files
- rag.ipynb: Main RAG notebook
- Ratha_Yatra.pdf: Source document
- requirements.txt: Python dependencies
- .env.example: API key template

## Setup
1. Clone this repository.
2. Install dependencies:
   pip install -r requirements.txt
3. Create a local .env file based on .env.example.
4. Add your Gemini API key to .env.
5. Open rag.ipynb in VS Code and run the notebook cells.

## Security
Never upload your real .env file or API key.
